# ИИ-агент

Раздел **«ИИ-агент»** (меню под аватаром) — всё, чтобы подключить к своим задачам
внешнего ИИ-помощника.

## Что там есть {#contents}

- **Токен** — отдельный ключ доступа (второй JWT для вашего же аккаунта, группы
  `USER` + `AGENT`, срок 48 часов, без продления). Создать / показать / скопировать
  / перевыпустить / удалить.
- **Адреса** API и файла описания OpenAPI, с кнопками «Скопировать» и «Скачать».
- Готовый **системный промпт** и примеры запросов.
- Список того, что агент **может** и **не может**.
- Карточка **«Всё одним куском»** — токен, адреса, правила и место под задачу
  одним Markdown-текстом, с «Скопировать всё» / «Скачать .md».

## Где хранится токен {#storage}

Только в вашем браузере. Приложение его **никуда не отправляет** — вы сами
вставляете токен в свой ИИ-клиент. «Удалить» очищает его локально (отзыва на
сервере нет). При выходе из аккаунта токен стирается.

## Что агенту доступно {#scope}

- задачи, комментарии, время, [[summary|резюме задачи]] — читать и изменять;
- вики — только **читать** (создавать и править страницы нельзя);
- всё, что требует прав администратора, — запрещено.

Действия через агента помечаются в задаче значком «через агента»
(см. [[comments-mentions#agent-badge]]).

## Профиль {#profile}

В разделе «Мой профиль» — только строка статуса токена и ссылка сюда.
