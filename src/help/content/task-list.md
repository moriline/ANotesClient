# Страница «Задачи»

Главный список задач по всем вашим проектам. Открывается пунктом «Задачи» в
верхнем меню.

## Поиск {#search}

Поле поиска ищет подстроку в **заголовке и описании**, **без учёта регистра**, и
только в проектах, где вы участник. Клавиша <kbd>/</kbd> ставит фокус в это поле.

Если ввести число (можно с `#`, например `104`) — это ищется как **номер
задачи**, а не подстрока: при выбранном проекте задача открывается напрямую по
id, без проекта — среди первых 500 доступных.

Быстрый глобальный поиск с переходом — палитра команд (<kbd>⌘</kbd>/<kbd>Ctrl</kbd>
+ <kbd>K</kbd>).

## Фильтры {#filters}

| Фильтр | Примечание |
|---|---|
| **Проект** | Нужен для фильтров «Статус», «Веха» и режимов группировки. |
| **Статус** | Значения из статусов выбранного проекта. |
| **Веха** | «Любая веха» / «Без вехи» / конкретная веха. См. [[milestones#in-task-list]]. |
| **Исполнитель** / «Назначено мне» | |
| **Тип** | Только задачи / только эпики. Работает в режиме «Список». Не путать с переключателем вида ниже — это про то, какие строки показывать, а не как их раскладывать. |
| **Теги** | Клиентский фильтр по тегам задачи. |
| **Архивные** | Тумблер — показать архивные задачи. |

Кнопка **«Сбросить»** появляется, когда активен хоть один фильтр.

## Режимы отображения {#views}

Переключатель вида справа в панели:

- **Список** — плоская таблица с пагинацией. Строки эпиков помечены значком пакета
  и прогрессом вместо статуса.
- **По эпикам** — задачи проекта сгруппированы под заголовками эпиков с прогрессом.
  Нужен выбранный проект; грузятся все задачи проекта. «Без эпика» — всегда
  последняя группа. По умолчанию группы **свёрнуты** — сначала видно эпики с
  прогрессом, разворачиваете нужный. <kbd>Shift</kbd> + <kbd>←</kbd>/<kbd>→</kbd> —
  свернуть/развернуть все.
- **Доска** — колонки по статусам проекта, карточки перетаскиваются между ними
  мышью (статус меняется сразу). См. [[#board]].
- **По вехам** — задачи проекта сгруппированы по вехам, по возрастанию срока, в
  конце «Без вехи». У заголовка — прогресс, счётчик, срок, число просроченных. В
  строке задачи виден её эпик.

Когда выбираешь проект с эпиками, вид сам переключается на «По эпикам» (если вы не
меняли его вручную и в URL нет `?view=`). Вид сохраняется в адресе страницы.

## Доска {#board}

Native drag-and-drop: тянешь карточку в другую колонку — задача переходит в этот
статус, оптимистично (с откатом при ошибке сервера). Виртуализации нет — для очень
длинных колонок это заметно.

## Массовые действия {#bulk}

Отметьте задачи галочками — появится панель: назначить исполнителя на все
выбранные или удалить их.
