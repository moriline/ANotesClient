# Разметка Markdown

Описания и комментарии форматируются через Markdown.

## Что поддерживается {#syntax}

| Пишете | Получаете |
|---|---|
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `` `код` `` | моноширинный фрагмент |
| ```` ```…``` ```` | блок кода |
| `# Заголовок`, `## …` | заголовки |
| `- пункт` / `1. пункт` | списки (вложенные — отступом) |
| `> цитата` | цитата |
| `[текст](https://…)` | ссылка |
| `| a | b |` со строкой `|---|---|` | таблица |
| перевод строки | так и остаётся переводом строки |

Опасный HTML вырезается при отображении.

## Где рендерится {#where}

| Поле | Отрендеренный вид | Живой предпросмотр |
|---|---|---|
| Описание задачи | да (после «Готово») | нет |
| Комментарии | да (после отправки) | нет |
| Описание вехи | да | нет |
| Содержимое вики-страницы | да | **да** — кнопка «Предпросмотр» в редакторе |
| Описание в форме создания задачи / вехи | — | нет, только сырой ввод |

Единственное место с двухколоночным живым предпросмотром — редактор
[[wiki#editor|вики-страницы]].

## Особые токены {#tokens}

- `@username` — упоминание участника (описание задачи, комментарии). См.
  [[comments-mentions#mentions]].
- В тексте вики-страницы дополнительно работают `[[Заголовок]]` (ссылка на
  страницу) и `#123` (ссылка на задачу). См. [[wiki#links]].
