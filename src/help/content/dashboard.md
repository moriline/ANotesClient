# Моя доска

Личная сводка «что назначено мне» через **все проекты сразу**, без выбора
одного проекта — в отличие от [[task-list]], где фильтры по статусу и вехе
работают только внутри выбранного проекта. Открывается пунктом «Моя доска» в
верхнем меню (первый пункт) или из палитры команд.

## Что показывается {#what}

Загружаются ваши незакрытые задачи (`assignedToMe`), без архивных, до 500
штук. Если назначенных задач больше — вверху появится строка «Показаны первые
N из M».

Задачи разбиты на три секции **по срочности**, а не по статусу:

- **Просрочено** — срок уже прошёл.
- **На этой неделе** — срок в пределах ближайших 7 дней.
- **Без срочности** — срок дальше недели или не задан.

Единой доски по статусам, как на [[task-list#board]], здесь нет: статусы —
per-project, и у задач из разных проектов нет общего набора колонок.

Отдельным блоком внизу — **«Недавно закрыто»**: задачи, закрытые за последние
сутки (зачёркнуты, приглушены). Закрытие происходит как обычно, на странице
задачи — здесь только витрина, чтобы не искать номер только что закрытой
задачи по всему списку [[task-list]]. Ориентир по времени — дата последней
правки задачи, а не отдельно хранимая «дата закрытия» (её в API нет), так что
если закрытую давно задачу сегодня просто отредактировали, она тоже ненадолго
попадёт сюда.

## Фильтры {#filters}

**Проект** и **Веха** — оба списка строятся из уже загруженных задач, без
дополнительных запросов к серверу. Значение «Без вехи» отдельно от «Любая
веха». См. также [[milestones]].

## Каждая строка задачи {#row}

Номер, заголовок, проект, веха (если есть), статус и срок — клик по строке
открывает задачу.
