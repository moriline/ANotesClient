# Эпики

Эпик — «шапка» над группой задач одного направления: «Уведомления», «Переезд на
новую БД», «Редизайн кабинета». Это **отрезок** во времени, в отличие от вехи —
**точки** (см. [[milestones]]).

## Чем эпик отличается от задачи {#vs-task}

- у эпика **нет исполнителя** и **нет своего статуса**;
- у эпика **нельзя списывать время** — «Списано» показывает сумму по вложенным
  задачам;
- **готовность эпика** считает сервер по вложенным задачам: сколько из них в
  закрывающем статусе;
- у эпика **не может быть вехи** — см. [[milestones#what]].

Маршрут у эпика и задачи общий (`…/tasks/<проект>/<номер>`), различаются только
блоки на странице.

## Страница эпика {#page}

Вместо статуса и исполнителя — **прогресс** (закрыто из всего). Ниже — **список
дочерних задач**: галочка слева переводит задачу между стартовым и закрывающим
статусом проекта (сразу, с откатом при ошибке).

## Сделать задачу частью эпика {#attach}

На странице обычной задачи — селектор **«Эпик»** в сайдбаре
(см. [[task-fields#epic]]). «Без эпика» — открепить.

## Преобразование {#convert}

Меню ⋯ на странице задачи → «Преобразовать в эпик» / «Преобразовать в задачу».
При превращении задачи в эпик снимаются исполнитель и статус, поэтому у задачи не
должно быть списанного времени и она не должна сама входить в другой эпик.

## Удаление эпика {#delete}

Меню ⋯ → «Удалить эпик». Если внутри есть задачи — диалог с выбором:

| Вариант | Что происходит |
|---|---|
| Открепить задачи | задачи остаются в проекте, но без эпика |
| Удалить вместе | удаляются и эпик, и вложенные задачи |

## Эпики на странице «Задачи» {#in-list}

- фильтр **«Вид»**: только задачи / только эпики;
- режим **«По эпикам»**: задачи сгруппированы под заголовками эпиков с прогрессом.
  Подробно — [[task-list#views]].

## Эпики на дорожной карте {#roadmap}

Каждый эпик — полоса на шкале от даты старта до срока. См. [[roadmap]].
