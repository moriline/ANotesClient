# Учёт времени

Списанное время ведётся на уровне **задачи** — карточка «Учёт времени» в сайдбаре
страницы задачи.

## Записи {#entries}

- **Добавить запись** — сколько времени и (обычно) за какую дату/с описанием.
  После сохранения всплывает уведомление «Время записано» с кнопкой
  **«Отменить»** — пока оно на экране, можно одним кликом удалить только что
  добавленную запись, без диалога подтверждения.
- **Удалить запись** — по кнопке возле неё в списке (с подтверждением).
- Сумма всех записей показана в заголовке карточки.

Автор записи — тот, кто её создал; в отчёте «по задаче» время разбивается по
авторам.

## Таймер {#timer}

Кнопка **«Запустить таймер»** в карточке «Учёт времени» — секундомер вместо
ручного ввода часов/минут. Работает целиком в браузере (без записи на сервер,
пока не остановлен): состояние переживает обновление страницы и переход между
разделами, а идущий таймер виден полоской под шапкой на **любой** странице —
не только на странице задачи, — с паузой и остановкой прямо оттуда.

Активен один таймер сразу. Если запустить его на другой задаче, пока этот
идёт, — сначала предложат записать или сбросить текущее время, и только потом
стартует новый. Остановка (или запись/сброс при переключении) открывает форму
с посчитанным временем — можно поправить длительность и добавить комментарий
перед сохранением, как при ручном вводе. Отдельная запись времени —
через уже описанный выше **`POST .../time`**, никакого отдельного способа
хранения для таймера нет.

## Эпики {#epics}

На **эпик время не списывается**. В карточке эпика «Списано» — это сумма по
вложенным задачам. Записи ведутся у самих задач внутри эпика.

## Отчёты {#reports}

Сводка за период и по проектам — на странице **«Отчёты»**, см. [[reports]].
