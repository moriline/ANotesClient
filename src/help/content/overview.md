# Обзор

ANotes — трекер задач и проектов. Эта справка описывает то, что видно в
интерфейсе; открыть её всегда можно клавишей <kbd>?</kbd> или из меню под аватаром.

## Из чего всё состоит {#objects}

- **Проект** — рабочее пространство. У проекта свои участники, свой набор статусов,
  своя база знаний и дорожная карта. Задача всегда принадлежит одному проекту.
- **Задача** — единица работы: заголовок, описание, исполнитель, статус, сроки.
  Подробно — в разделе [[task-fields|Поля задачи]].
- **Эпик** — «шапка» над группой задач одного направления. У эпика нет исполнителя
  и своего статуса, прогресс считается по вложенным задачам. См. [[epics|Эпики]].
- **Веха** — контрольная точка по сроку (релиз, демо, дедлайн). Собирает задачи из
  разных эпиков «к одной дате». См. [[milestones|Вехи]].

Эпик и веха — **две независимые оси**: эпик отвечает на вопрос «что делаем», веха —
«к какому числу». У задачи может быть и то, и другое одновременно.

## Куда идти {#navigation}

| Хочу | Где |
|---|---|
| Мои задачи через все проекты сразу | **Моя доска** (верхнее меню) — см. [[dashboard]] |
| Список задач, фильтры, поиск | **Задачи** (верхнее меню) — см. [[task-list]] |
| Открыть/создать проект | **Проекты** |
| Сроки проекта на шкале | иконка-календарь в строке проекта → [[roadmap|Дорожная карта]] |
| Релизные точки | иконка-ромб в строке проекта → [[milestones|Вехи]] |
| Документация проекта | иконка-книга в строке проекта → [[wiki|База знаний]] |
| Списанное время | **Отчёты** — см. [[reports]] |
| Настройки профиля, пароль | меню под аватаром → **Мой профиль** — см. [[account]] |
| Подключить ИИ-агента | меню под аватаром → **ИИ-агент** — см. [[agent]] |

## Полезно знать сразу

- **Сохранения по кнопке нет** почти нигде: поля на странице задачи пишутся на
  сервер сразу после изменения. Явно подтверждаются только заголовок и описание.
- **Поиск** (<kbd>/</kbd> или ⌘/Ctrl+K) ищет по заголовку **и** описанию, без учёта
  регистра, только в проектах, где вы участник.
- Всё, что можно, считает **сервер** — прогресс, состояния вех, просрочки. Вручную
  эти значения не выставляются.
- Полный список клавиш — в разделе [[keyboard|Горячие клавиши]].
