# Дорожная карта

Временная шкала эпиков проекта: одна полоса на эпик, по его срокам. Показывает,
что и к какому времени будет готово.

## Где открыть {#where}

Страница **«Проекты»** → в строке проекта иконка-календарь (рядом с ромбом «Вехи»
и книгой «База знаний»). Отдельного пункта в верхнем меню нет — карта всегда про
один проект.

## Полосы эпиков {#bars}

Каждый эпик — горизонтальная полоса от даты старта до срока.

- **Свои даты эпика** — берутся, если заданы.
- **Выведенные даты** — если у эпика своих дат нет, они считаются по вложенным
  задачам; такая полоса рисуется **пунктирной рамкой**.
- **Два слоя полосы:** внешний прямоугольник — окно срока в приглушённом цвете
  состояния; внутренняя заливка — прогресс `закрыто / всего задач` в насыщенном
  цвете. То есть длина заливки = насколько эпик готов.
- **Состояние** (не начат / в работе / готов / под риском / просрочен) и признак
  «есть просроченные дети» — считает сервер, клиент их не пересчитывает.

Эпик показан как `#id` (буквенных ключей нет).

## Масштаб {#scale}

Переключатель в шапке: **неделя / месяц / квартал**. По умолчанию масштаб
подбирается по длине диапазона. Выбор запоминается в адресе страницы (`?scale=`) —
ссылку можно передать.

## Линия «сегодня» {#today}

Вертикальная линия через все строки — только если сегодняшняя дата попадает в
видимый диапазон.

## Вехи на карте {#milestones}

[[milestones|Вехи]] рисуются **вертикальными линиями с ромбом** поверх полос
эпиков, по своим срокам. На широком экране над шкалой — строка «Вехи» с подписями.
Клик по ромбу ведёт на страницу вехи.

Польза: видно, **укладывается ли эпик в релиз**. Полоса эпика заканчивается правее
ромба вехи — часть работы в этот релиз не попадёт.

## Эпики без сроков {#no-dates}

Если у эпика нет ни своих дат, ни задач с датами — он попадает в список **«Без
сроков»** под шкалой. Этот список не скрывается: такие эпики видно всегда, чтобы
про них не забыли.

## Чего здесь нет {#limits}

Перетаскивания полос мышью нет — даты меняются на странице эпика/задач.
