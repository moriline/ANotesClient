# Задачи

Задача — единица работы внутри проекта. У неё есть заголовок, описание,
исполнитель, статус и сроки. Отдельные поля разобраны в разделе
[[task-fields|Поля задачи]].

## Открыть задачу {#open}

- со страницы **[[task-list|Задачи]]** — клик по строке;
- из результатов поиска (<kbd>/</kbd> или ⌘/Ctrl+K);
- по прямой ссылке `…/tasks/<проект>/<номер>`.

Задача адресуется парой «проект + номер» — получить её по одному номеру нельзя,
поэтому в ссылке всегда есть проект. Номер показывается как `#104` (буквенных
ключей вроде `TSK-104` в системе нет).

## Как сохраняются изменения {#saving}

На странице задачи **нет кнопки «Сохранить»**:

- **Статус, исполнитель, срок, дата начала, оценка, теги, эпик, веха, архив** —
  пишутся на сервер сразу после выбора, с откатом при ошибке. Правки ставятся в
  очередь, чтобы два быстрых изменения подряд не конфликтовали.
- **Заголовок и описание** редактируются явно: нажимаете на текст → правите →
  «Готово». Пока правите описание, черновик раз в секунду сохраняется в браузер;
  при возврате на страницу появляется плашка «Несохранённый черновик —
  Восстановить / Отбросить».

Если ту же задачу в это время изменил кто-то ещё, при сохранении заголовка или
описания появится диалог **«записать поверх / перезагрузить»**. Быстрые правки в
таблице на странице «Задачи» такого диалога не показывают — там побеждает
последнее сохранение.

## Статусы {#statuses}

Статусы **свои у каждого проекта** (не общий список). Каждый статус проекта либо
«обычный», либо **закрывающий** — задача в закрывающем статусе считается
выполненной. Отдельного поля «резолюция», как в Jira, нет.

Настраиваются статусы на странице **Проекты** → меню строки → «Статусы»
(переименование, цвет, порядок, «закрывающий», «скрытый»). Удалять статусы нельзя.

## Архив {#archive}

Задачу можно **архивировать** (меню ⋯ на странице задачи или переключатель в
сайдбаре) — она пропадает из списков, но не удаляется. Показать архивные — тумблер
«Архивные» на странице [[task-list|Задачи]].

## Удаление {#delete}

Меню ⋯ → «Удалить задачу». Обычная задача удаляется по подтверждению. Удаление
**эпика** с вложенными задачами — отдельный диалог с выбором (открепить детей или
удалить вместе), см. [[epics#delete|Эпики]].

## Приоритет, ключи, теги-сущности {#not-here}

Чего в задачах **нет** (описано в общей спецификации, но не реализовано в API):

- **поля приоритета** — badge и фильтр приоритета отсутствуют;
- **буквенных ключей** (`TSK-104`) — только номер `#104`;
- **тегов как отдельной сущности** — теги это просто список строк, см.
  [[task-fields#tags]].
