# Отчёты по времени

Страница **«Отчёты»** (верхнее меню) — сводка списанного времени.
См. также [[time-tracking]].

## Три вкладки {#tabs}

- **По пользователю** — сколько времени списал выбранный пользователь за период, с
  разбивкой.
- **По проекту** — списанное время по выбранному проекту.
- **По задаче** — время по конкретной задаче с разбивкой по авторам записей.
  Считается на клиенте из записей задачи (у серверных отчётов разбивки по
  пользователям для задачи нет).

## Период {#period}

Год и месяц. **Месяц «весь год»** = данные за весь выбранный год.

## Ссылка на отчёт {#link}

Вкладка, период и выбор (пользователь / проект / задача) отражаются в адресе
страницы — конкретный отчёт можно скинуть ссылкой.

## Экспорт в CSV {#export}

На вкладках «По пользователю» и «По проекту» — кнопка **«Экспорт CSV»** в шапке
страницы: выгружает ту же разбивку, что видна на экране (по строке на проект/
пользователя + «Итого»), файлом, который открывается в Excel/Google Таблицах.
На «По задаче» экспорта нет — там и так виден полный список списаний на странице.

## «Отчёт недоступен» {#forbidden}

Если у вас нет общего проекта с выбранным пользователем (или вы не участник
проекта), отчёт закрыт — это нормально, показывается строкой «Отчёт недоступен», а
не ошибкой.
