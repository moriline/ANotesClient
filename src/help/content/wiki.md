# База знаний

Вики проекта: связанные Markdown-страницы с деревом, ссылками между собой и на
задачи, историей версий.

## Где открыть {#where}

Страница **«Проекты»** → в строке проекта иконка-книга. Адрес —
`…/projects/<проект>/wiki`. База знаний всегда про один проект.

## Дерево и чтение {#tree}

Слева — дерево страниц (вложенность два уровня), справа — выбранная страница. Под
каждым заголовком в дереве — краткое описание страницы:

- обычный текст — авторская строка «о чём страница»;
- курсив + «Автопревью» — это не авторская строка, а начало содержимого;
- «Без описания» — у страницы только Markdown-текст, отдельного описания нет.

## Ссылки в тексте {#links}

- `[[Заголовок страницы]]` — ссылка на другую страницу проекта. Если страницы с
  таким заголовком нет, ссылка **красная** и ведёт на создание.
- `#123` — ссылка на задачу с этим номером (именно номер, не `TSK-123` — буквенных
  ключей нет). Система находит проект и заголовок задачи сама.

Блок «Упоминается в» на странице показывает, какие страницы ссылаются на текущую.

## Редактор {#editor}

Отдельный экран («+ Страница» или «Изменить»).

- **Краткое описание** — обязательно при создании (1–500 символов), одно
  предложение «о чём страница». При редактировании: пустое поле = «оставить как
  есть».
- **Содержимое** — Markdown. Кнопка **«Предпросмотр / Редактор»** включает
  двухколоночный режим с живым рендером — это единственное место в приложении с
  предпросмотром Markdown.
- **Черновик** автосохраняется в браузер; при возврате предлагается восстановить.
- **Раздел** (родительскую страницу) задают только при создании — переместить
  страницу по дереву потом нельзя.
- Сохранение всегда проверяет версию: если страницу изменили параллельно, будет
  диалог «перезагрузить / записать поверх».

## Файлы и картинки {#files}

Вложения — панель **«Вложения»** под содержимым (и в редакторе, и на самой
странице). В редактор файл кладётся тремя равноценными способами:

- перетаскиванием в поле «Содержимое»;
- вставкой из буфера обмена (<kbd>Ctrl</kbd>+<kbd>V</kbd> после скриншота);
- кнопкой **«Загрузить»** в панели вложений.

Ссылка на файл — обычная Markdown-разметка (`![подпись](адрес)` для картинок,
`[подпись](адрес)` для остального), никакой особой схемы ссылок нет: страницу
можно скопировать в другой редактор Markdown, картинки останутся на месте.
Картинка отображается прямо в тексте, остальное — ссылкой на скачивание.
Кнопка **«Вставить»** в панели добавляет ссылку на уже загруженный файл на
место курсора повторно — на случай, если ссылку в тексте убрали, а файл нужен
снова. Прикреплять файлы можно только у уже сохранённой страницы.

Удаление файла, на который ещё есть ссылка в тексте, спрашивает
подтверждение — после удаления картинка или ссылка в тексте станет битой.

## История версий {#history}

На странице — «История»: список ревизий с автором и комментарием к правке,
построчное сравнение соседних версий. **«Восстановить эту версию»** = записать
старый снимок как новую версию (краткое описание при этом не трогается — ревизии
его не хранят).

## Поиск {#search}

Палитра команд (<kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd>) ищет и по вики —
совпадения по заголовку, тексту и краткому описанию, без учёта регистра.

## Доступ для ИИ-агента {#agent}

Агент может **читать** вики (дерево, страницы, поиск), но **не может** создавать
или редактировать страницы. См. [[agent]].
