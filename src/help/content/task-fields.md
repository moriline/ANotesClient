# Поля задачи

Разбор полей на странице задачи. Все поля сайдбара сохраняются сразу после
изменения — см. [[tasks#saving|Как сохраняются изменения]].

## Описание {#description}

Поддерживает [[markdown|разметку Markdown]] и упоминания `@username`
(см. [[comments-mentions]]). Редактируется явно: клик по тексту → правка →
«Готово». Живого предпросмотра здесь нет — размеченный текст виден после
сохранения.

## Заголовок {#title}

Однострочный, обязательный. Правится так же, как описание (клик → «Готово»).

## Статус {#status}

Значение из набора статусов **этого проекта** (см. [[tasks#statuses]]). У эпика
своего статуса нет — вместо него прогресс по вложенным задачам.

## Исполнитель {#assignee}

Один участник проекта или «не назначен». У эпика исполнителя нет.

## Срок {#due}

Дата, к которой задачу нужно закрыть. Влияет на пометки просрочки:

- если срок в прошлом, а статус не закрывающий — задача считается **просроченной**
  (в том числе для счётчика вехи, см. [[milestones#overdue]]);
- если срок задачи **позже** срока её вехи — в списке задач вехи стоит значок ⚠.

Очистить срок можно, оставив поле пустым — задача без срока в просроченные не
попадает.

## Дата начала {#start}

Необязательная. Используется на [[roadmap|дорожной карте]] как левый край полосы,
если задача — часть эпика без собственных дат.

## Оценка, ч {#estimate}

Ожидаемая трудоёмкость в часах. **Справочное поле**: в расчёт прогресса и
состояний вех оно не идёт — там считаются задачи по штукам, не часы
(см. [[milestones#states]]). Burndown по стори-поинтам в системе нет.

## Теги {#tags}

Теги задачи выбираются из **списка тегов проекта**. Свободного ввода на задаче нет
— словарь тегов задаётся на странице проекта. На странице [[task-list|Задачи]]
есть фильтр по тегам. Отдельной страницы тегов с их редактированием/цветами нет.

## Эпик {#epic}

Привязка задачи к эпику — направлению работы. Выбирается из списка эпиков проекта,
пункт «Без эпика» отвязывает. У задачи не больше одного эпика. Подробно —
[[epics]].

## Веха {#milestone}

Привязка к контрольной точке по сроку. В списке — только **открытые** вехи
проекта; «Без вехи» отвязывает. У задачи не больше одной вехи. К **закрытой** вехе
привязать задачу нельзя. Подробно — [[milestones]], способы привязки —
[[milestones#add-tasks]].

## Учёт времени {#time}

Карточка в сайдбаре: список записей о списанном времени, добавление и удаление.
Сумма показывается в заголовке карточки. У эпика показывается сумма по вложенным
задачам — на сам эпик время не списывается. См. [[time-tracking]].

## Резюме {#summary}

Короткое изложение задачи на 2–4 предложения — «что сейчас происходит». Заполняете
вы или [[agent|ИИ-агент]] — суффикс «(AI)» в заголовке блока появляется, только
когда агент подключён. Отдельный раздел: [[summary]].

## Файлы {#files}

Вложения задачи: загрузка, скачивание, для картинок — превью, для текстовых
файлов — просмотр в модалке. Удаление — по кнопке ×.

## Комментарии {#comments}

Обсуждение задачи. Markdown и упоминания `@username`, отправка по
⌘/Ctrl+Enter. См. [[comments-mentions]].
