# Горячие клавиши

Работают, когда фокус не в поле ввода.

## Глобальные {#global}

| Клавиша | Действие |
|---|---|
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd> | Палитра команд — поиск задач, вики, быстрый переход |
| <kbd>/</kbd> | Фокус в поле поиска |
| <kbd>C</kbd> | Новая задача |
| <kbd>?</kbd> | Открыть справку |
| <kbd>Esc</kbd> | Закрыть палитру / модалку / выйти из режима правки |

## В группировках {#grouping}

На странице [[task-list|«Задачи»]] в режимах «По эпикам» и «По вехам»:

| Клавиша | Действие |
|---|---|
| <kbd>Shift</kbd> + <kbd>→</kbd> | Развернуть все группы |
| <kbd>Shift</kbd> + <kbd>←</kbd> | Свернуть все группы |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Свернуть/развернуть группу под курсором |

## В редакторах текста {#editors}

| Клавиша | Действие |
|---|---|
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Отправить комментарий / сохранить поле |
| <kbd>@</kbd> | Список участников для упоминания |
| <kbd>Esc</kbd> | Отменить правку |
